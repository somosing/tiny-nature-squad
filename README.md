# Tiny Nature Squad 🌻🐛🐞

A full-screen mobile swipe-only snake-style game.

## Gameplay

- Press **Start chaos**.
- Swipe anywhere to move the worm.
- Collect sunflowers.
- Avoid ladybugs.
- At 12 sunflowers, the worm becomes butterfly mode.

## v6 changes

- Removed all visible arrow controls.
- Removed keyboard controls too.
- Removed visible exit button.
- Combined score and butterfly progress into one tiny, almost-transparent HUD.
- Made popups almost invisible.
