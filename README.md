# Tiny Nature Squad 🌻🐛🐞

A full-screen mobile snake-style game.

## Gameplay

- Press **Start chaos**.
- The game switches into full-screen play mode.
- Swipe anywhere to move the worm.
- Collect sunflowers.
- Avoid ladybugs.
- At 12 sunflowers, the worm becomes butterfly mode.
